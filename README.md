# Saffran Patisserie Web Preview

A modern, minimal single-page website concept for Saffran Patisserie located in Baulkham Hills, NSW.

## Getting started

Open `index.html` in your browser to explore the layout. The page pulls in Google Fonts over the network and contains responsive styling optimised for mobile and desktop viewing.

## Structure

- `index.html` – page markup and content.
- `styles.css` – visual design system and responsive layout rules.
- `script.js` – enhancements for the mobile navigation toggle, animated reveals, interactive hover tilt, and dynamic footer year.
